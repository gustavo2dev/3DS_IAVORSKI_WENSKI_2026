Testador: Classe Termometro

Esta página contém a classe Termometro (não modificada). Abra o console do navegador para testar a tranca (setter que só aceita números). 

        
// Exemplo 1 no console
t.temperatura          // → 25
t.temperatura = "abc"  // tentativa: deve ser ignorada

// Exemplo 2 no console
t.temperatura          // → 25
t.temperatura = 30;    // → 30  (novo número)

Dica: cole as linhas no Console (F12) do navegador. A classe usa propriedade privada #temperatura, então apenas o getter expõe o valor.
