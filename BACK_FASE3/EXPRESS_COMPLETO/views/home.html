🚀 Servidor Express Completo

Integração de todos os recursos EXPRESS_0 até EXPRESS_10

ℹ️ Sobre: Este servidor integra todas as funcionalidades dos 11 projetos Express, incluindo rotas dinâmicas, banco de dados SQLite, middlewares, logging com Morgan e funções modularizadas.

📍 Rotas Básicas

GET / - Página inicial
GET /sobre - Informações sobre
GET /info - Informações do servidor
GET /servicos - Página de serviços

👥 Rotas de Clientes (EXPRESS_07)

GET /clientes - Lista todos os clientes
GET /total_clientes - Total de clientes
GET /clientes/:id - Exemplo: /clientes/1

🔢 Rotas com Parâmetros (EXPRESS_06, EXPRESS_08)

GET /ola/:nome - Exemplo: /ola/João
GET /ola/:nome/:empresa - Exemplo: /ola/João/TechCorp
GET /soma/:a/:b - Exemplo: /soma/10/20
GET /produto/:pA/:pB - Exemplo: /produto/5/3
GET /distancia/:pontoA-:pontoB - Exemplo: /distancia/10-50
GET /distancia/:pontoA.:pontoB - Exemplo: /distancia/10.50

🧮 Rotas com Funções Modularizadas (EXPRESS_09)

GET /add/:a/:b - Exemplo: /add/10/5
GET /sub/:a/:b - Exemplo: /sub/10/3

💾 Rotas do Banco de Dados (EXPRESS_10)

GET /tasks - Listar todas as tarefas
GET /tasks/add/:task/:status - Adicionar tarefa
GET /setup - Configurar banco com dados padrão
GET /setup/iavorski - Configurar com dados customizados
