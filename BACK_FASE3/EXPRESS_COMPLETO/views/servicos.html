🛠️ Serviços Disponíveis

📝 Gerenciamento de Tarefas

Sistema completo de gerenciamento de tarefas com banco de dados SQLite. Crie, visualize e gerencie suas atividades.

👥 API de Clientes

Base de dados com informações de clientes. Acesse, busque e manipule dados de clientes cadastrados.

🔢 Calculadora Online

Operações matemáticas via API. Soma, subtração, multiplicação, divisão e cálculo de distâncias.

📊 Logging em Tempo Real

Monitoramento de todas as requisições HTTP com Morgan. Visualize método, status, URL e tempo de resposta.

🔗 Rotas Dinâmicas

Sistema flexível de rotas com parâmetros compostos e tratamento de redirecionamentos automáticos.

💾 Persistência de Dados

Banco de dados SQLite integrado para armazenamento permanente de tarefas e informações do sistema.
