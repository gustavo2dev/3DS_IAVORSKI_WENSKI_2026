# 🚀 Aprendizado de Back-End com Node.js

Este repositório documenta minha jornada de aprendizado em desenvolvimento back-end utilizando Node.js. Aqui você encontrará desde scripts básicos com módulos nativos até a criação de um servidor web funcional com rotas e páginas HTML.

## 📚 O que foi estudado

- Módulos nativos do Node.js: `http`, `fs`, `os`
- Criação de servidores HTTP
- Roteamento de páginas (URLs)
- Leitura e escrita de arquivos (síncrona e assíncrona)
- Manipulação de pastas (criar, remover)
- Exportação e importação de módulos
- Tratamento de erros e códigos de status HTTP

## 📁 Estrutura do projeto

- `app.js` / `app1.js` – Scripts iniciais explorando os módulos `fs` e `os`
- `server.js` – Evolução do servidor: do básico ao roteamento completo
- `dados.js` – Exemplo de modularização com `require` e `module.exports`
- `dados.csv` – Arquivo de exemplo para leitura com `fs`
- `/HTML` – Pasta com as páginas servidas pelo servidor:
  - `home.html`
  - `sobre.html`
  - `servicos.html`
  - `contato.html`
  - `404.html`

## ▶️ Como executar

1. Tenha o Node.js instalado.
2. Clone o repositório.
3. No terminal, execute: `node server.js`
4. Acesse `http://localhost:3000` no navegador.

Navegue pelas rotas: `/home`, `/sobre`, `/servicos`, `/contato`. Rotas inexistentes exibem a página 404 personalizada.

## 💡 Objetivo

Praticar os fundamentos do back-end com Node.js, entendendo como um servidor web funciona por baixo dos panos e como entregar conteúdo dinâmico ao cliente.
